## 👨‍💻 Hakkımda
Süleyman Demirel Üniversitesi'nde Bilgisayar Mühendisliği eğitimime devam ediyorum. Almanya'daki Hochschule Schmalkalden'de tamamladığım Erasmus+ değişim programı ile uluslararası bir akademik vizyon edindim. Bilgisayar donanımları, sistem mimarileri, modern web geliştirme süreçleri ve algoritmik problem çözme konularına yoğun bir ilgim bulunuyor.

## ✨ Özellikler
* **Modern ve Responsive Tasarım:** Tüm mobil ve masaüstü cihazlarla tam uyumlu, sade bir arayüz.
* **Kapsamlı Profil Sunumu:** Eğitim hayatım, projelerim ve teknoloji, strateji oyunları, seyahat gibi kişisel ilgi alanlarımın derli toplu bir sunumu.
* **Hızlı Performans:** Gereksiz yüklerden arındırılmış, optimize edilmiş statik yapı.

## 🛠️ Kullanılan Teknolojiler

* **Sürüm Kontrolü:** Git & GitHub
* **Deployment (Yayın):** Vercel
